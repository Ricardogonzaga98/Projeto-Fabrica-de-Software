# Validação de Fluxo do Sistema

O fluxo do sistema foi definido para garantir uma navegação simples e eficiente.

## Fluxo Principal

1. Usuário acessa a tela de login
2. Realiza autenticação
3. Acessa a tela principal (dashboard)

---

## Fluxo de Cadastro de Documento

1. Usuário seleciona "Novo Documento"
2. Preenche os dados obrigatórios
3. Salva o documento
4. Sistema gera número de protocolo automaticamente

---

## Fluxo de Consulta

1. Usuário acessa "Consultar Documentos"
2. Aplica filtros de busca
3. Visualiza resultados
4. Pode acessar detalhes do documento

---

## Fluxo de Atualização de Status

1. Usuário acessa documento
2. Altera o status
3. Sistema registra no histórico

---

## Validação

O fluxo foi analisado pela equipe e considerado:

- Simples
- Intuitivo
- Coerente com os requisitos do sistema
