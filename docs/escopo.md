# Escopo do Sistema SCED

O sistema SCED tem como objetivo controlar a entrada e o acompanhamento de documentos de forma digital, substituindo o processo manual atual.

## Escopo Definido

O sistema contemplará funcionalidades essenciais para:

- Registro de documentos
- Consulta de informações
- Controle de status
- Histórico de movimentações
- Geração de relatórios simples

## Limitações

Funcionalidades avançadas como integrações externas, automações complexas e recursos adicionais não serão implementadas nesta fase.

## Validação

O escopo foi definido com base nos requisitos do projeto e validado pela equipe, garantindo foco no problema principal e viabilidade de entrega dentro do prazo.
